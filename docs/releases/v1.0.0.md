The first public release of Godot Co-op: real-time collaboration for the Godot editor.

**[Download GodotCoop-windows.zip](https://github.com/i-Roboticist/godot-coop/releases/download/v1.0.0/GodotCoop-windows.zip)**, unzip it anywhere and run `GodotCoop.exe`. Prefer the plugin on its own? Grab `godot_coop_plugin.zip`.

### Highlights
- Live scenes: nodes, properties, sub-resources, groups and signals sync as you edit.
- Shared scripts: type in the same file at once, with teammates' carets and per-user undo.
- Presence: see selections, cursors and 3D cameras; follow a teammate; ping things.
- One invite code: the app downloads the project and the matching Godot version.
- Play for everyone, with automatic connections for multiplayer games.
- Peer to peer, end-to-end encrypted, host approval and review of files that can run code.

### Good to know
- Windows may show "Windows protected your PC" because this build isn't code-signed yet. Click **More info**, then **Run anyway**.
- Everyone in a session needs the same Godot version (4.4 or newer); the app downloads it for you.
