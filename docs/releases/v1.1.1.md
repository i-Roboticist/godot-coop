Dropping assets into the FileSystem dock, done right.

**[Download GodotCoop-windows.zip](https://github.com/i-Roboticist/godot-coop/releases/download/v1.1.1/GodotCoop-windows.zip)**, unzip it and run `GodotCoop.exe`. Works with 1.1.0, but everyone should update.

- When you drop an image (or any asset) or a script into the FileSystem dock, teammates get it with *your* import settings and UID. Before, their Godot could make its own `.import`/`.uid` with a different UID and send it back, which could flip UIDs and show "changed by two people at once" notices.
- Godot's regenerated `.import`/`.uid` files never produce conflict copies.
- Files that arrive while Godot is already scanning get imported as soon as the scan finishes (they could wait until you switched windows).
- New tests: dropping images and scripts on either side, moving an asset to another folder, and an editor importing an asset before the sender's import file arrives.
